# The Blackboard

The Blackboard is the classroom board beside the drawing in BlackCAD's
workbench (`BOARD`, F1): subjects, units, lessons and steps, each step a
chalk figure drawn from live numbers, a few sentences, and a live rule
check or an exercise the board checks in the open drawing. Its code is the
last section of `apps/web/app.js`; the measurements behind Check my
drawing come from the core (`check-holes`, `cad_core::check`).

| File | What it is |
|---|---|
| `CURRICULUM.md` | What is taught now (Drafting, Shop), what is planned (Electronics, Machining), and notes for the next builds. Updated 2026-10-15. |
| `SHOP-ADVISORY.md` | The advisory of 2026-10-09 that the Shop lessons were built from: principles, roadmap, accuracy and clean-room rules. |
| `LESSON-SOURCES.md` | Every lesson's rules and formulas, their public sources, which numbers are placeholders, and the reviewers' sign-off (pending for all). |

These are the project's records as written, with file references updated
to this folder. Later changes to the lessons are recorded here and in
`docs/CHANGELOG.md`.
